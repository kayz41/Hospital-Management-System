# 🏥 Hospital Management System

A desktop-based Hospital Management System developed using **Java Swing** and **Microsoft SQL Server** to manage hospital operations efficiently and securely.

---

## 📖 Project Overview

The Hospital Management System is designed to simplify hospital administration by providing modules for managing patients, doctors, appointments, billing, pharmacy, laboratory services, medical records, staff, user accounts, and reports. The system also implements **Role-Based Access Control (RBAC)** and **Audit Trail Logging** to improve security and accountability.

---

## ✨ Features

- 🔐 Secure user login and authentication
- 👥 Role-Based Access Control (RBAC)
- 📝 Audit trail logging
- 👨‍⚕️ Doctor management
- 🧑 Patient management
- 📅 Appointment management
- 💳 Billing management
- 💊 Pharmacy management
- 🧪 Laboratory management
- 📂 Medical records management

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kayz41/Hospital-Management-System.git
   ```

2. Open the project in Apache NetBeans IDE.

3. Install and configure Microsoft SQL Server.

4. Create the `HospitalManagementDB` database.

5. Import your SQL tables.

6. Update the database connection settings in `DatabaseConnection.java`.

7. Build and run the project.

---

## ▶️ How to Use

1. Launch the application.
2. Log in with a valid username and password.
3. Navigate through the dashboard.
4. Manage hospital records using the available modules.
5. Log out securely when finished.
